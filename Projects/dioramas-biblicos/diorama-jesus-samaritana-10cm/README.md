# Diorama Jesus e a Mulher Samaritana — 10 cm

Backup oficial do projeto de diorama bíblico em escala 1:32.

## Regras

- O conteúdo interno/texturas internas do projeto original devem ser preservados.
- A caixa externa pode ser ajustada para o padrão universal desenvolvido para a
  coleção bíblica.
- Arquivos Blender e outros binários grandes usam Git LFS.
- Código e infraestrutura do MCP não pertencem a esta pasta.
- O caminho local da estação não é salvo neste repositório.

## Estrutura prevista

- `source/` — arquivos editáveis principais do projeto.
- `exports/` — GLB/STL/outros exports deliberados.
- `references/` — referências visuais e técnicas necessárias ao projeto.
- `checkpoints/` — marcos relevantes de trabalho.
