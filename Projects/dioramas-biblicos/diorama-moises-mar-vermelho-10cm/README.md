# Diorama Moisés — Mar Vermelho — 10 cm

Arquivo final independente da coleção bíblica, usando a caixa universal de 100 × 100 × 100 mm e escala 1:32.

- A cena interna é preservada por projeto.
- A caixa externa segue o padrão universal compartilhado da coleção.
- Arquivos `.blend` e binários 3D usam Git LFS.
- A infraestrutura MCP permanece no repositório `mcp-blender` e não é duplicada aqui.
